# Data Structures & Algorithms Implementation (Princeton Curriculum)

A comprehensive repository of foundational data structures and algorithms based on the Princeton University computer science curriculum.

## 🎯 Objective
This project focuses strictly on mathematical time and space complexity efficiency, bridging theoretical algorithmic design with robust, production-ready Python implementations.

## 🧠 Core Implementations & Mathematical Complexity
Below is a snapshot of the implemented structures and their theoretical limits:

| Data Structure / Algorithm | Search / Access Time | Insert Time | Space Complexity |
| :--- | :--- | :--- | :--- |
| **Binary Search Tree (BST)** | $O(\log n)$ | $O(\log n)$ | $O(n)$ |
| **Hash Tables** | $O(1)$ | $O(1)$ | $O(n)$ |
| **Merge Sort** | $O(n \log n)$ | N/A | $O(n)$ |
| **Quick Sort** | $O(n \log n)$ | N/A | $O(\log n)$ |

## 🚀 Technologies & Concepts
*   **Language:** Java
*   **Core Concepts:** Object-Oriented Programming (OOP), Asymptotic Analysis (Big O), Memory Management, Recursion, and Graph Theory.
